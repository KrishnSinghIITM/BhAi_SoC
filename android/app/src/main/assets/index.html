What is the maximum allowable trace width reduction if mechanical scrape is needed?

Under IPC-A-610G Table 5-1:

• Maximum permitted reduction in conductor width or cross-sectional area is 20% for Class 2 and Class 3 products.

• If copper trace loss exceeds 20%, mechanical scrape is prohibited; route board to jumper wire rework or scrap.
